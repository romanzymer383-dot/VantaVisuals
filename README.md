# Vanta Visuals (prototype)

Fabric client prototype for Minecraft 1.21.11.

- Right Shift: toggle the small HUD (FPS, XYZ, facing).
- M: append a waypoint coordinate to `config/vanta-visuals-markers.txt`.

This prototype does not include PvP target tracking or player ESP. It is a source project, not a tested/compiled release. Gradle dependency versions may need adjustment and compilation/testing with Java 21 and Gradle is still required.

Build: run `gradlew build` after adding the Gradle wrapper, or use an installed Gradle 8.x/compatible setup with Java 21.
